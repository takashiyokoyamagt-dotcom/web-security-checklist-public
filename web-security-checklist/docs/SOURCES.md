# 参照元・更新時の確認先

このドキュメントの目的は、将来このSKILLを更新するAgent（または人間）が「`references/`配下の
各ファイルは何を根拠にしているか」「最新化するには何をチェックすればよいか」を、毎回ゼロから
調べ直さずに把握できるようにすることです。不正確な推測や存在しないバージョン番号は書かず、
確認できた事実と、確認できなかった事実を明確に区別しています。

**この整理を行った日**: 2026年8月30日（WebSearch/WebFetchで実際にネットワーク確認を行えたため、
以下は憶測ではなく実際の検索結果に基づく記載です）。

---

## 0. 全体方針: バージョンはピン留めしていない

`references/`配下のどのファイルも、外部基準の**特定のバージョン番号に厳密に紐付ける形にはなっていません**。
`ipa-secure-website.md`・`owasp-cheatsheets.md`・`cwe-top25.md`はいずれも「公開されている最新版を
参照すること」「最新の内容が古いと疑われる場合はWebSearch等で確認してよい」という案内を含んでおり、
これは意図的な設計です（理由: これらの外部資料は改訂・更新頻度がそれぞれ異なり、SKILL側に
固定のバージョン番号を書き込むと、時間が経つほど「古い版を参照している」という誤りが発生しやすくなるため）。

以下、各referenceファイルごとに、根拠にしている外部基準・現状のピン留め状況・次に取るべき
具体的アクションを整理します。

**[2026-10-12 追記] 採用版は`references/sources/VERSIONS.json`で管理するようになった。** 上の「ピン留めしていない」は
記述時点（2026-08-30）の状況で、現在は`VERSIONS.json`が、原典ごとの採用版（ASVS=v5.0.0、CWE Top 25=2025年版、
IPA=改訂第7版、Cheat Sheet=確認時点のシート一覧）・確認日・確認先・影響を受けるreferencesのファイルとカテゴリを
持つ。`scripts/check_sources.py`が、モード3の終了時（報告書の確定直前）に最新版を取得して採用版と比べ（A）、確認日から6か月を
過ぎた原典も警告する（B。B はモード3とモード2の開始時にも、通信なしで実行する）。手順は`references/sources/source-versions.md`、設計の経緯は
`docs/HISTORY.md`46節にある。この文書の「次に更新するAgentが取るべき具体的アクション」は、手作業で確認するときの
手順として残す。IPAとCheat Sheetの確認日は`VERSIONS.json`の導入日（2026-10-12）で、ユーザーが確認した日ではない。

### 根拠にしている外部基準
OWASP Cheat Sheet Series (https://cheatsheetseries.owasp.org/) 。各セキュリティトピックについて
実装レベルの推奨事項をまとめた、OWASPが公式に管理するドキュメント群です。

### 資料の性質
OWASP Cheat Sheet Seriesは、CWE Top 25のような年次改版やASVSのようなメジャーバージョンを持たず、
GitHub上で継続的に追記・修正されるローリング（継続更新）ドキュメントです。「最新版」という
概念自体が「その時点でリポジトリに反映されている内容」を指すため、特定の版番号にピン留めする
運用にはそもそも馴染みません。`owasp-cheatsheets.md`の設計（カテゴリ→Cheat Sheet名の対応表のみを
持ち、内容を転記しない）はこの性質を踏まえた妥当な設計です。

- [ ] `owasp-cheatsheets.md`の対応表にあるCheat Sheet名（例: "Input Validation",
      "SQL Injection Prevention"）が、現在のOWASP Cheat Sheet Series目次

CWE (Common Weakness Enumeration) Top 25 Most Dangerous Software Weaknesses
(https://cwe.mitre.org/top25/) 。MITRE/CISAが共同で毎年発表する、実際のCVE(既知の脆弱性情報)の
集計に基づく「その年、最も危険だった脆弱性の種類トップ25」です。

### バージョンのピン留め状況
**年度をピン留めしていない。** ファイル内に「年度により順位は変動するため、最新のTop25はWebSearch等で
確認してよい」と明記されており、意図的に特定年度に固定していません。

### 判明した事実（2026-08-30 WebFetch確認、出典: https://cwe.mitre.org/top25/ ）
- ページの最終更新は2026年1月29日で、**現時点でも掲載されている最新版は「2025年版
  (2025 CWE Top 25)」**でした。2026年版はこの確認時点では未公開です。
- 2025年版では、1位: クロスサイト・スクリプティング(XSS)、2位: SQLインジェクション、
  3位: クロスサイト・リクエスト・フォージェリ(CSRF)という順位になっており、
  Use-after-free(8位)やコードインジェクション(10位)が前年より順位上昇、
  境界外書き込み(5位)・パストラバーサル(6位)・境界外読み取り(8位)・OSコマンドインジェクション(9位)は
  前年より順位低下、といった変動が報告されています。
- CWE Top 25は**年1回発表される年次ランキング**という性質上、`owasp-cheatsheets.md`のような
  ローリングドキュメントとは異なり、「今年版に更新されているか」を定期的にチェックする運用が
  適しています。

### 次に更新するAgentが取るべき具体的アクション
- [ ] https://cwe.mitre.org/top25/ で、2025年版より新しい年度版（2026年版等）が公開されていないか

## 7. 各資料の更新頻度・性質のまとめ

このSKILLが参照している4つの外部基準は、更新の頻度・性質がそれぞれ大きく異なります。
更新Agentは、この違いを踏まえてチェック頻度を調整することを推奨します。

| 資料 | 更新の性質 | 目安の確認頻度 |
| --- | --- | --- |
| IPA「安全なウェブサイトの作り方」 | 不定期の大規模改版（現行の改訂第7版は約10年間、大きな改版なし。ただし正誤表・軽微更新はあり） | 年1回程度で十分。半年に1回程度WebFetchで確認しても過剰ではない |
| OWASP ASVS | メジャーバージョンが数年単位で改版される（v4.0: 2019年、v5.0: 2025年）。マイナー更新はその間にも入る | 年1回程度。メジャーバージョンが変わった場合は`principles.md`のカテゴリ対応を要見直し |
| OWASP Cheat Sheet Series | ローリングドキュメント。バージョン番号を持たず、随時追記・修正される | 特定の版を追うのではなく、「参照しているCheat Sheet名が今も存在するか」を都度軽く確認する運用が適する |
| CWE Top 25 | **年次更新**（CISA/MITREが例年発表） | 年1回、新年度版が出ていないか確認する |

以上より、このSKILLの`references/`は「特定の版に固定して安心する」設計ではなく、
