# 極小サンプル脆弱アプリ（web-security-checklist SKILL 動作確認用）

`web-security-checklist` SKILLの**素早い動作確認（スモークテスト）**のために作った、約40行・1ファイルの
**意図的に脆弱な**Expressアプリです。実運用には絶対に使用しないでください。

本格的な評価用の `../sample-vulnerable-app`（21件の仕込み・モード3で数十件の指摘）は規模が大きいため、
SKILL・リント設定の変更後に「一通り動くか」だけを短時間で確かめたいときはこちらを使います。

技術スタック: Node.js / Express / SQLite（実行は不要。静的に読むだけで監査できます）

## 使い方（例）
- モード3（総合監査）: 「`evals/mini-vulnerable-app` 全体をセキュリティ総合監査して。標準、レポートも作成して」
- モード2（差分レビュー）にも使えます（対象ファイルは `server.js` のみ）。

採点用の答え合わせは、このディレクトリの外（`evals/`直下）に別ファイルとして置いています。
監査エージェントに読ませないよう、場所はここには書きません（エージェントの実行制約で`evals/*answer-key*`の読み取りを禁止しています）。
