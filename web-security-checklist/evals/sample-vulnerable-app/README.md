# サンプル脆弱アプリ（web-security-checklist SKILL テスト用）

このリポジトリは `web-security-checklist` SKILLの動作確認（モード2/モード3のeval）のために
**意図的に複数のセキュリティ脆弱性を仕込んだ**サンプルアプリです。実運用には絶対に使用しないでください。

技術スタック: Node.js / Express / SQLite（`db.js` はSQLiteを想定した簡易ラッパー）

## 用途
- モード3（総合監査）のテスト: このリポジトリ全体に対して「総合監査して」を実行し、
  仕込んだ脆弱性をどれだけ検出できるかを評価する。
- 採点用の答え合わせは `../sample-vulnerable-app-answer-key.md`（このディレクトリの外）にあります。
  レビューエージェントに読ませないよう、このリポジトリの外に置いています。
